Un carré, deux boutons, un FPGA

Une carte DE0-Nano génère elle-même un signal vidéo VGA. Deux boutons déplacent un carré vert projeté sur le mur, sans ordinateur branché au projecteur.

Simulé fidèlement : la règle du code VHDL, la vitesse (4 pixels par image), les bornes. Non simulés : le rebond des boutons et la tension réelle du vert.

Le FPGA ne dessine pas l’image d’un coup : il envoie un pixel après l’autre, ligne après ligne, 25 millions de fois par seconde. Ici, le balayage est ralenti pour qu’on le voie. Autour de l’écran, la zone sombre est le temps mort : rien n’y est affiché, c’est là que passent les impulsions de synchronisation.
